# 4.1 机械共振物理模型与瞬态响应

> “高速打印最大的敌人不是马达的力矩，而是机架自身的弹性与惯性。”

当 3D 打印机的加速度突破 $5000\sim 20000\text{ mm/s}^2$ 时，打印件垂直转角处经常出现一圈圈像水波纹一样的微小涟漪。这种现象在社区中被称为**振纹、重影（Ghosting）或鬼影（Ringing）**。

在传统观念中，解决振纹的唯一办法是降速降加速度，或者换更笨重粗壮的金属机架。
而 Klipper 引入了现代航空航天与高精数控中的前馈控制理论——**输入整形（Input Shaping）**，使普通轻量化机架也能在极高加速度下打印出镜面般平整的表面。

本节我们将从经典二阶振动系统切入，揭示机械共振的数学本质。

---

## 一、 二阶弹簧-阻尼系统建模

打印头的运动传动链本质上是一个弹性系统：
* 步进电机输出刚性位移；
* 同步带（带齿橡胶与玻璃纤维线芯）相当于一根刚度为 $k$ 的弹性弹簧；
* 挤出头、散热块、风扇组件构成了集中质量 $m$；
* 轴承滚珠、导轨润滑油与皮带内耗构成了粘性阻尼 $c$。

```text
       步进电机驱动端                从动弹性负载 (打印头)
          [ X_in(t) ]                 [ X_out(t) ]
              |                            |
              +---/\/\/\/\----+---[===]---+---> (集中质量 m)
                   刚度 k           阻尼 c
```

根据牛顿第二定律，打印头的相对动力学微分方程为：
$$m \ddot{x}(t) + c \dot{x}(t) + k x(t) = f(t)$$

两边同除以质量 $m$，写成控制理论中的标准二阶系统传递函数形式：
$$\ddot{x}(t) + 2 \zeta \omega_n \dot{x}(t) + \omega_n^2 x(t) = \omega_n^2 u(t)$$

其中：
* $\omega_n = \sqrt{\frac{k}{m}}$：**无阻尼固有角频率（Natural Frequency）**，它决定了机架在几赫兹（通常为 30~80 Hz）容易发生剧烈共鸣。
* $\zeta = \frac{c}{2\sqrt{km}}$：**阻尼比（Damping Ratio）**，3D 打印机的同步带阻尼比通常很小，在 $0.05 \sim 0.15$ 左右，属于典型的**欠阻尼系统（$\zeta < 1$）**。
* $\omega_d = \omega_n \sqrt{1 - \zeta^2}$：**有阻尼共振角频率**。

---

## 二、 瞬态冲激与阶跃响应：为什么急停会激发“鬼影”？

当欠阻尼二阶系统受到一个单位冲激输入 $\delta(t)$ 时，其时域冲激响应为：
$$h(t) = \frac{\omega_n}{\sqrt{1 - \zeta^2}} e^{-\zeta \omega_n t} \sin(\omega_d t)$$

这代表着一个以共振频率 $\omega_d$ 剧烈衰减振荡的阻尼正弦波：

```text
机架振幅 x(t)
  ^
  |      /\
  |     /  \
  |    /    \        /\
  |   /      \      /  \        /\
--+--+--------\----+----+------/--\------+---> 时间 t
  |            \  /      \    /    \    /
  |             \/        \  /      \  /
  |                        \/        \/
```

### 打印件表面的“空间声波印记”
在第 2 篇中我们知道，梯形加减速的加速度在拐弯减速时会发生急停。急停产生的力阶跃，相当于对机架连续施加冲激激发。

由于机架阻尼较小，急停后打印头会在空间中持续抖动数十个毫秒。而此时挤出机仍在持续以速度 $v$ 匀速出丝，抖动的位移便像刻录唱片一样，在塑料表面印出了一条条间距为 $\lambda = \frac{v}{f_d}$ 的肉眼可见微型波纹！

## 三、 反相相消干涉：输入整形的核心启示

既然急停会导致弹性形变引发振动，能不能用“以毒攻毒”的思路解决？

假设我们在时刻 $t_0 = 0$ 给机架施加一个幅值为 $A_1$ 的正向冲激，机架开始向前起振；
如果我们在**刚好半个振动周期之后（$T_d / 2 = \frac{\pi}{\omega_d}$）**，在振动恰好到达反向极值点时，精准施加第二个幅值大小刚好相等的冲激 $A_2$：

$$A_2 = A_1 \cdot e^{-\zeta \pi / \sqrt{1-\zeta^2}}$$

**这两个反相波形将在空间中发生完美的破坏性相消干涉（Destructive Interference）！**
机架在承受了两次推拉之后，总位移向前平移，而机架内部的残余机械振荡**瞬间归零**！

```text
冲激 1 诱发振动:  /\    /\    /\
冲激 2 诱发振动:    \  /  \  /  \  /   (延时半个周期反向施加)
------------------------------------------------------
相消干涉合成:     /---\_________________ (残余振动归零!)
```

这就是输入整形技术的最原始思想——**零振动整形器（Zero Vibration, ZV）**。
