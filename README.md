# 深入理解 Klipper：现代 3D 打印机控制架构与核心算法

> 基于 Klipper 源码深度剖析，揭秘软硬协同、分布式实时时钟同步与高级运动控制背后的数学与工程实现。

---

## 为什么写这本书？

传统的开源 3D 打印机固件（如早期的 Marlin、Repetier、RepRapFirmware）大多运行在单片机（MCU，如 8 位 AVR 或 32 位 ARM Cortex-M）上。在这些架构中，单片机不仅要负责解析复杂的 G-code 文本、计算轨迹规划、进行运动学逆解，还要精确控制多路步进电机的纳秒级硬件定时脉冲，以及管理温控 PID 和屏幕交互。

随着高速打印（>300 mm/s）与精密成型的普及，单片机有限的算力、受限的内存与单片架构逐渐成为系统的性能天花板。

**Klipper 颠覆了这一传统，提出了一种革命性的“双脑分布式协同”体系：**
* **大脑（上位机 Host - Klippy）**：运行在算力充沛的应用处理器（如 Raspberry Pi 或 x86/ARM Linux SBC）上，使用 Python 处理复杂逻辑、G-code 流水线、前瞻速度规划（Lookahead）、运动学解算以及共振补偿（Input Shaping）。
* **小脑（下位机 MCU - Firmware）**：运行在微控制器上，剥离一切繁琐的计算与文本解析，只保留精简的 C 语言硬实时定时调度器，专注在精准无抖动的时间点触发硬件脉冲。

这种软硬分离的架构不仅解构了运动控制工程的复杂度，也让 3D 打印进入了**全解析计算与闭环共振抑制**的新时代。

本书旨在**穿透应用层表象，直击系统内核**：从通信协议到微秒级时钟漂移同步，从梯形速度规划到 `itersolve` 步进求解器，从现代控制论中的输入整形（Input Shaping）到 MCU 极端优化的定时器中断队列。

## 源码版本与环境

* **源码基准**：Klipper 主线版本（包含 `klippy/` Python 上位机与 `src/` MCU 固件）
* **涉及语言**：Python 3.x（上层逻辑与算法规划）、C 语言（底层性能加速模块 `chelper` 与 MCU 微调度内核）
* **配套仿真**：随书提供 `simulations/` 目录，无需连接打印机，即可用纯 Python 代码运行并验证时钟漂移滤波、前瞻梯形规划和振动整形器频域特性。
